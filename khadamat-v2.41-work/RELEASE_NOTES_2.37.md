# خدمات V2.37

## تحسين شاشة تفاصيل وتتبع الطلب
- إضافة زر لنسخ رقم الطلب من شاشة تفاصيل الطلب.
- عرض طريقة الدفع ضمن معلومات الطلب.
- إضافة مسار «لم يصلني الطلب» لإرسال بلاغ مرتبط بالطلب إلى الإدارة باستخدام نظام الشكاوى الحالي (فئة NO_SHOW).
- الحفاظ على الدردشة الحية الحالية وأزرار التواصل والتتبع.

## التحقق
- تم بناء المشروع بنجاح عبر `npm run build`.
- بدأ تشغيل مجموعة الاختبارات عبر `npm test`، لكن عملية الاختبار الكاملة تجاوزت مهلة التنفيذ في بيئة العمل؛ لذلك لا يُدّعى اجتياز جميع الاختبارات.
