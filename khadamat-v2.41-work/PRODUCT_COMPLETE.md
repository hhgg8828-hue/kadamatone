# خدمات — النسخة التشغيلية المتكاملة

هذه النسخة تجمع دورة تشغيل المنصة في مشروع واحد متماسك بدل الإصدارات الصغيرة.

## المسارات الأساسية
- عميل: تسجيل/دخول، تصفح الكتالوج، بحث، طلب خدمة، GPS-first، مواقع محفوظة، متابعة الطلب، الإلغاء، عروض الأسعار، المحادثة، الشكاوى، التقييم، الإشعارات.
- مقدم خدمة: تسجيل، ملف، خدمات، وثائق، توثيق، موقع أساسي، أوقات التوفر، استقبال الطلبات، عروض ثابتة، عروض أسعار، مراحل التنفيذ، اتجاهات، محادثة، شكاوى، تقييم العميل، الأرباح.
- إدارة: لوحة تشغيل، مستخدمون، مقدمو الخدمات، توثيق، كتالوج، مناطق، إعدادات، طلبات، شكاوى، سجل تدقيق.

## الثبات والأمان
- SQLite في وضع MVP/تطوير، مع طبقة Db قابلة للاستبدال.
- idempotency للطلبات.
- optimistic locking للطلبات.
- RBAC وصلاحيات على مستوى الطلب والمحادثة والملفات.
- سجل حالات الطلب وسجل تدقيق إداري.
- SSE للإشعارات مع polling احتياطي.
- تخزين الملفات محليًا مع طبقة StorageProvider.
- دفع CASH حاليًا عبر PaymentProvider، ويمكن إضافة بوابة حقيقية كتنفيذ مستقل.

## التشغيل
```bash
npm install
npm run build
npm run seed:demo
npm start
```

## قبل الإطلاق التجاري
هذه النسخة هي أساس MVP تشغيلي قوي وليست بديلًا عن تجهيزات الإنتاج الخارجية: PostgreSQL مُدار، Redis/queue مُدار، تخزين ملفات object storage، HTTPS/domain، بوابة دفع محلية، FCM/APNs، مراقبة/نسخ احتياطي، سياسات خصوصية وشروط استخدام، واختبار تحميل.
