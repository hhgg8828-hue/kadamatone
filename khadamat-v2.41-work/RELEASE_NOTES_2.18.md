# خدمات 2.18.0 — تحسينات استجابة وإتاحة واجهة العميل

- تحسين التفاف شريط الهوية وأزرار الرأس على الشاشات الصغيرة لتقليل التزاحم.
- توحيد مؤشر التركيز المرئي لعناصر التفاعل بلوحة المفاتيح مع الحفاظ على ألوان وهوية «خدمات».
- تحسين سلوك شرائط العروض والفئات على الشاشات اللمسية، مع إلغاء حركات التحويم غير المناسبة للأجهزة التي لا تستخدم مؤشرًا.
- تعزيز المسافات الآمنة أسفل الشاشة لأجهزة الهاتف ذات مناطق النظام، وتحسين مساحة أزرار التنقل وإرسال الطلب.
- تحديث مفاتيح أصول الواجهة وذاكرة Service Worker إلى 2.18 لتقليل ظهور الملفات المخزنة القديمة.
- لم تتغير واجهات API أو منطق الطلبات أو قاعدة البيانات في هذا الإصدار.

## التحقق
- تمت مراجعة التعديلات النصية وفحص سلامة ملفات HTML/CSS/JS وملفات الحزمة.
- لم يُنفذ بناء TypeScript أو مجموعة الاختبارات الآلية في بيئة العمل الحالية لعدم توفر `node_modules`.
- لا يُدّعى اختبار بصري على هاتف فعلي أو نشر على Railway.
