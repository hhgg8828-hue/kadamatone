# Release 2.34 — تبسيط تنفيذ الطلب وفق تدفق توصيل وان

- جعل شاشة البداية تعرض بيانات الخدمة الضرورية فقط، وتُظهر مربع التفاصيل العام عند الحاجة (خدمات عرض السعر أو عندما يصل وصف من الوصول السريع).
- استخدام حقول الوصف الخاصة بالخدمة عندما تكون موجودة، ومنع تكرار سؤال الوصف.
- إزالة مربع «ملاحظات أو صورة» وملخص الطلب المكرر من شاشة البداية؛ تبقى الملاحظات اختيارية في شاشة التفاصيل/التأكيد.
- نقل العنوان ورقم التواصل إلى شاشة تفاصيل الطلب، بدل عرضهما في أول خطوة.
- تغيير زر الخطوة الأولى إلى «متابعة».
- إبقاء شاشة التفاصيل مختصرة، وتتضمن قسيمة التخفيض الاختيارية، ملخص الطلب، العنوان ورقم التواصل، الملاحظات الاختيارية، وقت الطلب، طريقة الدفع، ثم «تنفيذ الطلب».
- بعد نجاح إنشاء الطلب، يظل العميل قادرًا على الانتقال إلى «متابعة الطلب».
- إزالة زر الإعلان الإضافي من رأس واجهة العميل، مع إبقاء العروض ضمن شريط العروض.
- تحديث أرقام الأصول والكاش وإصدار API إلى 2.34.0.
- إصلاح ترتيب البناء بحيث يتم تجميع واجهة الويب قبل نسخها إلى مجلد التوزيع.
