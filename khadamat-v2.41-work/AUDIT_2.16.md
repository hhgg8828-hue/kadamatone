# مراجعة الإصدار 2.16.0

- أساس التعديل: مشروع 2.15.0 الذي يتضمن التغطية الجغرافية القابلة للإدارة وإعدادات العلامة التجارية والحملات.
- التغيير مركز على واجهة العميل فقط: ترتيب العرض، التباين، شريط الأخبار، شريط الحملات، بطاقات الفئات، بطاقات الخدمات الشائعة، شريط التنقل السفلي، وتنسيق رأس متابعة الطلب ونموذج الطلب.
- عنصر الوصول السريع ما زال `quickAssistForm` مع `quickAssistText` و`quickAssistVoice`، ولم يُعد نموذج الخطوات الثلاث.
- بقي اختيار الموقع من المناطق النشطة مع خيار تحديد الموقع، ولم تتغير API المناطق.
- نقر حملة مرتبطة بخدمة أو طلب أو مشوار يفتح التدفق المرتبط؛ الحملات الأخرى تفتح تفاصيل العرض.
- أضيف رفع صورة للقسم من لوحة الكتالوج، وتُحفظ مرجع الصورة داخل حقل `icon` الحالي بصيغة `/api/v1/files/<id>` لتجنّب تعديل قاعدة البيانات؛ يبقى متوافقًا مع الأقسام القديمة ذات الرموز النصية.
- لم تُغيّر صلاحيات الإدارة أو مقدم الخدمة أو قواعد قاعدة البيانات.
- تم تحديث `?v=2.16` ومفتاح ذاكرة الخدمة إلى `khadamat-shell-v2-16`.
