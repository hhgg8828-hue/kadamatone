# خدمات 2.16.0 — تحسين الواجهة الرئيسية للعميل

## ما الجديد
- إعادة تنظيم واجهة العميل استنادًا إلى صور المرجع التي زوّد بها المستخدم، مع الحفاظ على ألوان وهوية «خدمات» وعدم نسخ علامة توصيل ون أو أصولها.
- إضافة شريط تنقل سفلي ثابت للعميل (الرئيسية، الخدمات، طلباتي، حسابي) مع احترام مساحة الأمان في الهواتف.
- تحسين شكل رأس متابعة الطلب ونموذج إنشاء الطلب، مع إبقاء معلومات الطلب مختصرة والإجراءات الحالية محفوظة.
- إبقاء «الوصول السريع» كما اتُّفق عليه: مربع واحد للكتابة وزر «تحدث»، دون العودة إلى نموذج الخطوات الثلاث أو رفع الصور داخله.
- تحسين وضوح خلفية منطقة الوصول السريع وتباين عنوانها ونصها.
- إظهار شريط «آخر الأخبار والعروض» دائمًا؛ يعرض النص الذي تضبطه الإدارة، أو رسالة إرشادية افتراضية إذا لم يُدخل نص.
- تحويل العروض المصوّرة إلى شريط أفقي قابل للسحب باللمس مع صور عريضة، ويمكن فتح الخدمة/الطلب مباشرة عند ضبط الإجراء المناسب للحملة.
- إضافة صف فئات خدمات مربعة قابلة للضغط مثل النقل والتوصيل والصيانة والسيارات والزراعة والخدمات المنزلية. يمكن للإدارة رفع صورة لكل فئة من محرر الأقسام؛ وإذا لم توجد صورة، يظهر رسم توضيحي خفيف.
- إعادة ترتيب الخدمات الشائعة في بطاقات أكثر وضوحًا، مع إبقاء اختيار المحافظة/المديرية/الحي وزر «موقعي».
- تحديث أرقام الأصول ومفتاح Service Worker إلى 2.16 لإبطال النسخ القديمة المخزنة.

## الحفاظ على الوظائف
- لم تتغير واجهات API أو صلاحيات المستخدمين أو تدفق إنشاء الطلب الأساسي.
- لم تُضف مكتبات واجهة جديدة أو مؤقتات تدوير تلقائي؛ الحركة الوحيدة هي شريط الأخبار، مع احترام `prefers-reduced-motion` وإيقاف الحركة عند مرور المؤشر.
- إذا لم تكن هناك حملات فعالة، تظهر بطاقة تعريفية عامة لا تدّعي وجود عرض تجاري.

## ملاحظات
- صور العروض الفعلية تُدار من لوحة التحكم ضمن «الحملات والعروض»؛ لا يتم اختلاق عروض أو أسعار.
- بطاقات الفئات تستخدم الصورة المسجلة للفئة إذا وفرها API، وإلا تستخدم رسمًا توضيحيًا داخليًا.
- لم يتم النشر على Railway ضمن هذا الإصدار.
